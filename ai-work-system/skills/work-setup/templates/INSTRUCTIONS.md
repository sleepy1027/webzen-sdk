# 사용자 지시사항 기록

모든 작업 전에 이 파일을 읽고 지킨다. 사용자가 지속적인 지시("앞으로는 ~", "~할 것", 형식·규칙·금지사항)를 주면
아래에 번호를 이어서 추가한다. 일회성 요청은 적지 않는다. 지시끼리 충돌하면 최신 것을 따르고 사용자에게 알린다.

형식:
## N. <짧은 제목> (YYYY-MM-DD)
- 원문: "..."
- 해석: ...
- 반영: <바뀐 파일/설정>

## 1. 지시사항 기록 (설치 시 기본)
- 원문: "지시한 건 md에 저장하여 참고할 것"
- 해석: 지속적인 지시는 이 파일에 남기고 작업 전에 참고한다.
- 반영: 이 파일, AGENTS.md 7절

## 2. 자가 개선 (설치 시 기본)
- 원문: "자가 업데이트 기능이나 개선 제안을 할 수 있을 것"
- 해석: 큰 작업 뒤 개선점이 분명하면 한 줄로 제안하고, 요청 시 self-improve로 점검·반영한다.
- 반영: AGENTS.md 8절, self-improve 스킬

## 3. 답변은 요약이 기본 (설치 시 기본)
- 원문: "왜 대답을 요구하면 논문을 쓰냐? 한 번에 보기가 어렵잖아. 내가 자세히 더 달라고 얘기하기 전에는 요약해서 얘기를 해줘."
- 해석: 결론 1~2줄 + 핵심 3~5줄, 한 화면 안. 표·출처·세부 근거는 "자세히" 요청 시에만.
- 반영: AGENTS.md 1-1절, smart-task 6단계
