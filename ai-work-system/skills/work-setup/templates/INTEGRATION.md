# 기존 환경과의 통합 규칙

work-system은 기존 회사·개인 스킬, 에이전트, 지침을 **대체하지 않고 빈 곳을 채운다.**
이 파일은 `work-setup`(또는 `self-improve`)이 기존 환경을 조사해 채운다. 직접 고쳐도 된다.

## 우선순위
1. 사용자가 지금 대화에서 한 지시
2. 프로젝트·회사의 기존 지침 (프로젝트 `CLAUDE.md`, 회사 스킬·플러그인, 조직 정책)
3. 이 파일의 라우팅 규칙
4. work-system `AGENTS.md`와 work-system 스킬

## 라우팅 (같은 목적의 스킬이 여럿일 때 무엇을 쓸지)
| 업무 | 사용할 것 | 함께 참고할 것 | 이유 |
|---|---|---|---|
| (예) 주간보고 | 기존 `company:weekly-report` | work-system `team-board`의 보드 데이터 | 회사 양식 유지, 데이터만 보드에서 |

## 충돌하는 규칙과 결정
| 기존 규칙 (출처) | work-system 규칙 | 결정 |
|---|---|---|
